## Additional owner requests

- Provider-picker examples: `gpt-6.1-sol`, `gemini-4-argon`, `openrouter/free`.
  These are display examples; configured models and fallback IDs are preserved.
- Sponsor metadata previously refreshed every 24 hours on launch/resume. It now
  revalidates hourly, requests HTTP revalidation, and supports earlier manual
  refresh subject to the existing request cooldown. Failures retain the last
  usable campaign, up to the existing 48-hour maximum age. A corner close button
  dismisses a campaign for eight hours, persisted across restarts; it can be
  dismissed repeatedly. An active timeline also redraws at dismissal expiry.
- Android backup selection admits private extensions instead of depending on
  MIME associations. Full backups are recognized by container entries even if
  Android renames a picked copy to `.zip`/`.bin`. Restore authentication and
  validation remain in place.
- Reminder and scheduled-arrival notifications include an expanded body capped
  at 1,200 characters. Spotlight geometry follows the selected density. Reveals
  load missing timeline pages and materialize the lazy target before pulsing.
  Concurrent paging requests coalesce. Compact skeleton bars also fit their
  actual card height.
- Markdown document source remains available to reading/search without being
  shown as an AI result.
- Update notes aggregate published stable releases newer than the installed
  version, up to the offered release, in descending order. Each release's
  English/Persian section is handled independently. History retrieval is
  optional and bounded to five pages of 100 releases; failure never hides a
  checksum-verified installer.
- One **Coming soon** module, **Security toolbox**, groups the supplied site's
  planned capabilities: AES-256-GCM text encryption/decryption with PBKDF2;
  MD5, SHA-1/256/384/512, SHA3-256 and RIPEMD-160 hashing; Base64, URL, Hex,
  Binary, Morse and ROT13 encoding/decoding; random passwords, passphrases and
  patterns with character/minimum/ambiguity controls; and encrypted local
  secret storage with import/export. This release adds catalog metadata only.
