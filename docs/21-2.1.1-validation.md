## Motion and performance boundaries

Existing route, sheet, list, filter and selection motion remains in place.
Additional motion is confined to optional summary/results content, editor AI
feedback, detail action presses and theme/icon selection. Shared helpers use
NexMotion durations and respect reduced motion. Stable children are not rebuilt
on each animation tick; hidden retained content has tickers, input and semantics
disabled. Reading surfaces stay opaque. New motifs are static custom painting
behind a repaint boundary, without a timer, animated shader or additional blur.
