# Nex 2.6.7 — Soft Light, OLED Night and native colour alignment

## Purpose and scope

Stage 6 of the approved Soft UI colour work documents and versions the five
verified implementation stages, without introducing new layout, animation,
card-badge or data changes. The last published version was **v2.6.6**
(`sanyzrn/DbsNex-releases`, checked on 2026-11-06), so this work uses 2.6.7.

## Changes delivered

1. **OLED Night:** `NexNightColors` centralises the true-black page,
   charcoal card/elevated ramps, muted ink, accent and functional outlines.
   `nexNightTheme` delegates to the already-existing
   `nexOledNightTheme`. The older `nexDarkTheme` is preserved.
2. **Soft Light:** `NexSoftLightColors` backs the white page, gentle
   neutral cards, readable accents, flat surfaces and custom-accent support.
   Its normal text/button accent follows `NexColors.accentStrongLight`;
   capture uses the brighter blue. App and appearance previews already use
   the corresponding Light, Soft Dark and OLED Night renderers.
3. **Visible inputs:** Minimal themes retain a one-pixel enabled text-field
   border matching `colorScheme.outline`. Focus, validation and
   focused-error state borders remain distinct. Decorative card outlines
   do not return.
4. **Native Android:** `values/colors.xml` and `values-night/colors.xml`
   mirror the new Light/Soft Dark surface and text tokens for launch and
   home widgets. The adaptive-icon artwork, Cycle colours and Android 12+
   wallpaper-derived Material You overrides remain unchanged.
5. **Small consistency fixes:** Assistant settings describe Night using
   the user's translated label; the bootstrap/recovery MaterialApp uses
   Soft Light and Soft Dark instead of the old library renderers.

## Guardrails and compatibility

- No schema, preference keys, migrations, stored data, note editing
  behaviour, card layouts, animations, badges or module rollout changes.
- Old preference value `dark` still resolves to Night; explicit Dark is
  `soft_dark` and explicit Night is `night`. This is display routing,
  not a saved-data rewrite.
- The theme preset gallery remains paused while stored choices are retained.
  Liquid Glass, custom accents, high contrast and RTL/LTR must remain intact.
- Functional text contrast >= 4.5:1 and visible-outline contrast >= 3:1
  are protected by existing tests; do not weaken those assertions.
- Android night resources follow the device's brightness, not Nex's
  explicitly chosen OLED Night; Android 12+ uses Material You for widgets.
- Work stayed on `codex/2.0-polish`, with stage commits, and did not
  create or merge a pull request.
