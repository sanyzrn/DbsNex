# 2.6.6 — focused test and CI hardening

Source: `codex/2.0-polish` at `30f607c175ac0f6ab711b5f1a4d7e5c74a27f846`.
Started only after public, non-prerelease 2.6.5 and Release run 41930198093
(including the full verify suite) succeeded. No merge, release or tag is part of this work.

## Changes

- `spec/` and `contracts/` select Dart, backend and sync. The redundant merge
  job is removed: core's ordinary `dart test` and backend's `src/**/*.test.ts`
  both run their conformance suites against `spec/merge-conformance.json`.
- PostgreSQL-backed HTTP cases cover code reuse, expiry, concurrent redemption,
  token expiry/revocation/unknown tokens, claimed device spoofing and tenant isolation.
- Dedicated PostgreSQL and Dart sync invocations require a successful report
  containing executed tests. Ordinary unit runs may still skip optional integration.
- Retrieval and sync jobs follow core/data/backend/contract dependencies;
  heavy AI deletion follows package/entry-point/dependency changes. Cheap AI
  boundaries run on every CI invocation, independently of those flags.
- PRs keep active modules and changed module directories. Shared module helpers,
  widgets, platform, localization, test helpers and package changes retain all Soon
  suites. Unknown module directories fail safe to all. Releases and `.github/`
  changes run everything. Habits bilingual screenshots remain in the manually
  runnable review workflow; the ordinary client job retains habits regressions.
- Every new APK must preserve package/signers, retain prior ABI support, and
  outrank the highest actual versionCode among all previous APKs, including splits
  and store. This protects split-to-universal and split-to-store upgrades. Existing
  store defines, installer-permission checks, checksums and publishing gates remain.
- CI has `contents: read`; release tags enter the shell as environment data.
  External actions in all five workflows use immutable commit SHAs. Their version
  comments preserve provenance; the existing monthly github-actions Dependabot
  group remains the update path. For manual refresh, resolve a release tag to its
  commit (dereference annotated tags), review its diff and run the workflow checks.
- Format checks cover changed maintained Dart sources against the recorded PR base
  (or the current commit's parent for a release invocation), without rewriting files.
- Due-label helpers accept an optional reference instant. Embedding mutation and
  embedding timestamps accept an optional repository clock; default behavior remains
  the system clock. Tests advance a fixed clock rather than sleeping.

## Version policy

This is an internal-only development version, recorded here and in the technical
changelog. Published 2.6.5 notes and all bundled user-facing notes are untouched.
The version guard still requires exact agreement between app/pubspec and the newest
version in either authoritative history; it now honors CLAUDE.md's explicit policy
that internal-only changes belong in the technical history. A future public release
still needs its own bilingual user-facing notes: `release_notes.py` remains strict.

## Deliberately unchanged

Timing budgets, golden tolerance, UI baseline ratchet, stress scheduling, disabled
Windows/iOS jobs, report-only 16 KB alignment and serial release verification/builds.
Publish remains downstream of successful verify and Android build. No retries added.

## Validation

Recorded in the final commit after focused tests. Full Android signing/building and
actual previous/new APK inspection run on GitHub's Android runner; local APK guard
checks use metadata failure fixtures and reject missing tools/metadata/artifacts.

Focused results:
- 34 Python guard checks, including resolved empty diffs, contract/module paths,
  non-empty report parsing, malicious tag handling, release dependencies and APK
  version/signature/package/ABI failures.
- Backend: typecheck, lint, production build and 52 ordinary tests passed.
- Real PostgreSQL 16: 5 HTTP auth cases and 4 existing service cases passed.
- Live Dart SyncClient matrix: all 13 cases passed; dedicated invocations without
  their enabling environment variable failed as required (both Node and Dart).
- Dart core conformance: 4 checks passed using the shared merge/note-type fixtures.
- Embedding backlog: 6 checks passed. Client due-label/version checks: 14 passed.
- Client and data analysis passed. Changed Dart formatting passed.
- Actionlint passed with only its warnings about the existing deliberately paused
  `if: false` Windows/iOS jobs excluded. Those jobs remain disabled.

The container has only UID 0 mapped and disallows Unix sockets. Local PostgreSQL
therefore ran with a temporary UID/stat compatibility preload and TCP only; its
SQL/migrations/auth code was unmodified. Local Node used `node --import tsx`
instead of the tsx CLI's Unix IPC pipe. GitHub keeps its normal PostgreSQL service.
