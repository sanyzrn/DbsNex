# Uniform collapsed timeline cards — 2.6.2

## Display contract

- Every `NoteCard` in collapsed mode uses `nexCardHeightFor(context)` without
  caption, reminder, urgency, attachment or note-type height additions. Existing
  Compact, Standard and Readable densities and accessibility scaling still apply.
- A bounded status rail sits beside the preview, following the interface
  direction. Note paragraphs keep their own RTL/LTR direction. Reminder, urgency
  and attachment marks are built only when present, in that order; missing marks
  leave no holes. Reminder wording compacts before becoming an icon with its
  full schedule retained in semantics and a tooltip. At narrow widths the group
  may wrap inside the existing card envelope.
- A text-note caption uses the last preview row, in the theme's secondary grey
  at normal weight. It does not add a row to the card. Primary text, media,
  checklist and link previews retain bounded space; the full note is unchanged.
- Show in full remains an explicit expanding mode. Its eligibility calculation
  accounts for the status width and the row used by a caption. Expanded notes
  retain captions and status marks.
- Voice durations and checklist overflow counts remain single-line and bounded
  when the rail leaves less preview width. Counts and schedules remain available
  to accessibility, and note data, search, reminders and AI logic are unchanged.
- The old inline `WidgetSpan`/measurement layout and its separate caption/footer
  branch are replaced by the shared collapsed template. No dependency is added.

  linear scaling through 3.2 and nonlinear scaling. They check equal heights,
  separated content/status bounds, packed mark order, caption contrast, reminder
  semantics, expansion and existing type previews.
- 7 client tests: Show in full menu behavior, bilingual caption/urgency actions,
  version alignment and the shipped changelog.
- Full UI package analysis with `--fatal-infos` and formatting pass.
- Rendered and visually inspected four matching sample cards in English/light
  and Persian/dark with bundled Inter, Vazirmatn and Material Icons fonts.
- No release or Android build is produced by this change. Device validation and
  PR CI remain separate from the targeted checks above.

## Client CI follow-up

- CI run `41806052111` passed the UI and other package jobs, but six client
  assertions exposed reminder regressions in the new collapsed layout. Its
  narrow rail shortened full recurring schedules even on wide cards, and
  subtracted other marks from the clock's width despite supporting wrapping.
- Allow full schedules more room on wide cards and reserve the measured compact
  clock width at larger text sizes. The rail still has the same anchor for a
  given width and text scale, independent of which marks a note contains.
  Other marks wrap inside the existing envelope instead of hiding the clock.
  Checklist gaps also shrink when accessibility sizing leaves little preview
  width, without changing the card height.
- All six original failing assertions pass unchanged: daily/weekly schedules
  in English and Persian, the large-text narrow-card clock with attachments,
  and the repeating reminder after leaving and returning to the timeline.
- Flutter 3.35.5 / Dart 3.9.2: **61 focused UI tests** and **15 client reminder
  tests** passed, plus full UI analysis with `--fatal-infos` and formatting.
  Added two UI regressions for unclipped clocks/counts, non-overlapping marks
  and equal card heights at 320 dp and 1.9x text in both directions. Full CI and
  Android builds still need to complete on the pushed commit.
